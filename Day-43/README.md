# Day 43 – Count Inversions in an Array

## Problem

Given an array, count the number of **inversions** in the array.

An inversion is a pair of elements `(i, j)` such that:

- `i < j`
- `arr[i] > arr[j]`

In simple words, if a bigger element appears before a smaller element, it forms an inversion.
