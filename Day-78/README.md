# Day 78 – Preorder Traversal of a Binary Search Tree

## Problem
Create a Binary Search Tree and display all its elements using preorder traversal.

## Example

**Input**
```text
7
50 30 70 20 40 60 80
```

**Output**
```text
Preorder traversal: 50 30 20 40 70 60 80
```

## Approach
1. Create a Binary Search Tree using the given values.
2. Visit and print the root node.
3. Traverse the left subtree recursively.
4. Traverse the right subtree recursively.

## Concepts Used
- Binary Search Tree
- Tree traversal
- Recursion
- Preorder traversal

## Complexity Analysis
- Time Complexity: O(n)
- Auxiliary Space Complexity: O(h), where h is the height of the tree.

## What I Learned
- How preorder traversal works.
- How to implement Root-Left-Right traversal using recursion.
- How to visit every node in a binary tree.
