# Day 57 – Remove All Occurrences of a Character

## Problem

Given a string and a character, remove all occurrences of that character from the string.

## Example

### Input

String = "programming"

Character = "m"

### Output

prograing

## Explanation

The character `m` appears twice in the string `"programming"`.

After removing both occurrences of `m`, the resulting string is:

`prograing`

## Approach

1. Take the string as input.
2. Take the character that needs to be removed.
3. Traverse the string character by character.
4. Check whether the current character is equal to the given character.
5. If it is different, add it to the result string.
6. Display the resulting string.

## Concepts Used

* Strings
* Character Traversal
* Loops
* Conditional Statements
* String Manipulation

## Complexity

* Time Complexity: O(n)
* Space Complexity: O(n)
