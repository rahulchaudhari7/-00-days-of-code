# Day 77 – Inorder Traversal of a Binary Search Tree

## Problem
Create a Binary Search Tree and print its elements using inorder traversal.

## Example
**Input**
```text
7
50 30 70 20 40 60 80
```

**Output**
```text
Inorder traversal: 20 30 40 50 60 70 80
```

## Approach
1. Insert the given values into a Binary Search Tree.
2. Traverse the left subtree.
3. Print the current node.
4. Traverse the right subtree.

## Concepts Used
- Binary Search Tree
- Recursion
- Inorder traversal
- Tree data structures

## Complexity Analysis
- Time complexity: O(n)
- Auxiliary space complexity: O(h), where h is the height of the tree.

## What I Learned
- How inorder traversal works.
- How recursion can be used to traverse a tree.
- Why inorder traversal of a BST produces values in sorted order.
